# Candidate M. tuberculosis complex drug-resistance loci to mask before
# running spectrumSplits.py.
#
# ---------------------------------------------------------------------------
# THIS LIST IS A STARTING POINT, NOT AN AUTHORITY.  VERIFY IT.
#
# These are gene NAMES and locus TAGS only -- deliberately no coordinates.
# annotate_sites.py resolves each one against the annotation file you supply,
# so the intervals come from your reference, not from this file.  That is the
# whole point: a name you can check beats a coordinate you cannot.
#
# The authoritative source is:
#   WHO, "Catalogue of mutations in Mycobacterium tuberculosis complex and
#   their association with drug resistance", 2nd edition, 2023.
#   Downloadable with genomic coordinates; cite this, not this file.
#
# Cross-check with TB-Profiler's database (which tracks the catalogue) before
# relying on the list.
#
# NAMES ARE ANNOTATION-DEPENDENT, so every locus is listed twice where it can
# be: once by the name people use, once by its locus tag.  A name can report
# NOT FOUND for three different reasons, and only the third is a mistake in
# this file:
#
#   - it is a gene_synonym rather than the Name (gidB for Rv3919c, mabA for
#     fabG1).  annotate_sites.py searches synonyms, so these resolve.
#   - the annotation does not carry it at all (mmpR5, fbiD in NC_000962.3).
#     The locus tag entry covers the locus; the name stays because it is what
#     the WHO Catalogue calls it.
#   - the name is wrong: there is no clpC, only clpC1 and clpC2, and no ddl,
#     only ddlA.  Those are corrected rather than paired.
#
# So read a NOT FOUND line rather than ignoring it: check whether another
# entry covers the locus before assuming it was masked.
# ---------------------------------------------------------------------------
#
# Masking whole loci rather than individual sites is the point of this list.
# Per-site masking of a top-N list does not converge: mask rpoB codon 445
# position 1 and position 2 of the same codon surfaces next.
#
# Use --promoter_flank (e.g. 200) so promoter mutations are covered too; several
# important ones (inhA/fabG1 -15, embA -16, pncA -11) are upstream of the CDS.
